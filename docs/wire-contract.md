# MVP wire contract v1
All tokens and public keys are base64url (no padding). Tokens 32 random bytes. Keys NaCl box 32 bytes. Device IDs random UUID. HTTPS required except explicit localhost development. No text logs.
POST /api/rooms {ownerToken, ownerPublicKey, name} => {roomId}. roomId server random UUID.
Authorization: Bearer ownerToken for owner HTTP operations.
POST /api/rooms/:roomId/pairing {pairToken} => {expiresAt} expires 120s. Only one token, consuming invalidates. Desktop assembles URL /#pair=<base64url JSON {v:1,endpoint,roomId,pairToken,ownerPublicKey,name,expiresAt}>. Secrets only URL fragment.
POST /api/rooms/:roomId/pair {pairToken,deviceId,publicKey,name,clientToken} => {status:'pending'}. Must be owner-online. One pending request. Notify owner {type:'pair-request',deviceId,publicKey,name}. Desktop shows SAS, user compares phone SAS then approves. Pending expires120s.
GET /api/rooms/:roomId/devices (owner bearer) => {devices:[{deviceId,publicKey,name}]}; DELETE .../devices/:deviceId owner bearer or own client bearer revokes and closes sender, notifies owner {type:'peer-revoked',deviceId}.
DELETE /api/rooms/:roomId owner bearer deletes room metadata and closes all.
WebSocket /api/rooms/:roomId/ws. First message {type:'auth',role:'owner',token:ownerToken} or {type:'auth',role:'sender',deviceId,token:clientToken}. Reply {type:'authenticated',role,status:'approved'|'pending'}. No tokens in URL. Reject Origin when present and not request.origin. Owner replacement closes old connection. No offline queue. Unauthenticated sockets limited and time bounded.
Owner gets {type:'peer-online',deviceId,publicKey,name} when approved sender connects. Sender gets {type:'owner-online'} after owner auth. Owner gets {type:'peer-offline',deviceId}; sender {type:'owner-offline'} when owner closes.
Owner sends {type:'pair-approve',deviceId} or {type:'pair-reject',deviceId}. Server replies {type:'pair-approved',deviceId} to both; owner already has pending public key. Sender cannot send relay until approved.
Authenticated {type:'relay',to:'owner'|deviceId,envelope:{v:1,nonce,ciphertext}} => {type:'data',from:'owner'|deviceId,envelope}. Only owner<->approvedsender. Offline => {type:'error',code:'peer_offline'}. Server only validates envelope sizes, never decrypts. All errors {type:'error',code}. No application payload logs.
Client encryption shared protocol package seal/open using nacl.box with sender secret & pinned peer public, random24byte nonce. Plaintext v1 has {kind, ...}. Context binding inside authenticated plaintext {v:1,roomId,sender,recipient}; shared decrypt checks exact expected values. SAS shared-secret-derived SHA256 with context, first 12hex chars grouped.
Owner fresh sessionId per socket login. Owner sends encrypted {kind:'ready',sessionId,targetLabel,paused}. Sender text plaintext {kind:'text',id:UUID,sessionId,text,sentAt,expiresAt}, max8192UTF8 bytes, TTL15s. Receiver rejects stale/future>5s, sessionmismatch, duplicate, paused, unauthorized. Sender never auto-replays onreconnect. Owner ACK encrypted {kind:'ack',id,status:'injected'|'rejected'|'unknown',code?}. ACK means OS injection not target save. UI preserves draft until explicit clear. Pending message15s timeout => unknown noresend.
